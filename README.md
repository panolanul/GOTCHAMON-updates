# GOTCHAMON 업데이트

[최신 온라인 런처 받기](https://github.com/panolanul/GOTCHAMON-updates/releases/download/v0.6.21/GOTCHAMON-Online-Launcher-0.6.21.zip) · [최신 배포와 변경 사항](https://github.com/panolanul/GOTCHAMON-updates/releases/latest)

## 플레이어

게임·Prism·기존 GOTCHAMON 런처를 종료한 뒤, 받은 ZIP을 전부 압축 해제하세요.
기존 이용자는 `GOTCHAMON Launcher` 폴더 내용을 평소 런처 폴더에 덮어씁니다.
`GOTCHAMON Launcher.exe`의 플레이를 누르면 필요한 게임 파일을 설치하거나 업데이트합니다.
처음 설치할 때에는 Minecraft Java를 소유한 Microsoft 계정으로 Prism에 로그인하세요.
플레이어가 GitHub에 로그인할 필요는 없습니다.

이후 게임 패치는 플레이할 때 자동 확인하고 적용합니다. 게임 실행 중에는 교체하지 않습니다.
계정·키 설정·볼륨·메모리·개인 그래픽 설정·개인 월드·지도·스크린샷은 보존하며, 배포 관리 설정은 갱신합니다.
이 런처는 관리되는 GOTCHAMON Prism 인스턴스를 사용합니다. CurseForge 프로필과는 별개입니다.

## 서버 운영자

서버 업데이트 ZIP을 받아 노트북 서버를 `stop`으로 완전히 종료한 뒤 동봉된 업데이트 도구를 실행하세요.
서버 월드와 플레이어 기록은 배포 파일에 포함되지 않습니다. 적용 전 서버에서 자동으로 백업합니다.
